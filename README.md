# 🚀 Projetos em destaque

## 🏥 MedFlow AI

**Assistente inteligente para consulta de protocolos clínicos e pré-operatórios.**

O MedFlow AI utiliza arquitetura **RAG (Retrieval-Augmented Generation)** para recuperar informações relevantes de uma base documental e gerar respostas contextualizadas utilizando Inteligência Artificial.

Uma das principais características do projeto é a **rastreabilidade das respostas**, apresentando ao usuário a fonte e a página do documento utilizado.

### Tecnologias

`Python` • `Gemini API` • `RAG` • `ChromaDB` • `SentenceTransformers` • `Gradio` • `Embeddings`

🔗 **Projeto:** [MedFlow AI](https://github.com/Julianajava/MedFlow-AI)
